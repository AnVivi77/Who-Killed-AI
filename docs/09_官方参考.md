# 09 · 官方参考

资料核对日期：2026-09-04。此文件提供实施时的核对入口，不能代替对本机包版本、真实设备和最新文档的检查。

- [Codex：AGENTS.md 项目指令](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：根目录 AGENTS.md 用于向 Codex 提供持续的项目说明。请把整个资料包作为项目打开，而不只打开空的 UnityProject 子目录。
- [Vuforia：Unity 入门](https://developer.vuforia.com/library/vuforia-engine/getting-started/development-environments/getting-started-vuforia-engine-unity/)：SDK 导入、ARCamera、许可配置、Image Target 设置与编辑器测试。已有工程保留其渲染管线；新工程模板参考当前指南。
- [Vuforia：Image Targets](https://developer.vuforia.com/library/vuforia-engine/images-and-objects/image-targets/image-targets/)：基于相机图像特征识别目标；目标可通过 Target Manager 或官方支持的运行时方式创建。数据库方案是本项目的默认选择。
- [Vuforia：支持版本与平台](https://developer.vuforia.com/library/vuforia-engine/platform-support/supported-versions/)：选择 Unity/SDK/发布平台时核对。Windows 编辑器可测试，不等于所有 Windows 发布形式都支持真实 AR；不得把 UWP 支持解释成任意桌面构建支持。

Vuforia 的跟踪回调、枚举和可用程序集名称应以实际安装 SDK 的 API 为准。此资料包不固定某个最新版本号，不包含或虚构 SDK 许可。
