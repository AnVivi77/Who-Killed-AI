# 01 · 需求与默认决策

## 已确认需求

项目是 Unity + Vuforia 交互艺术解谜展览，当前已有 Unity 工程和多类素材；剧情文案、设备与正式验收仍有明确待确认项。

| 编号 | 必须实现的行为 |
| --- | --- |
| R01 | 每轮从先导视频开始，介绍案件背景 |
| R02 | 调查体验围绕尸体及散落线索展开 |
| R03 | 嫌疑人数可配置，每人对应两条线索 |
| R04 | 用 Vuforia 识别线索图像 |
| R05 | 识别后显示所属嫌疑人的档案及已解锁线索 |
| R06 | 尚未找到的线索区域只显示问号/未发现 |
| R07 | 同一人的两条线索齐全后，播放其事件/作案动画 |
| R08 | 所有嫌疑人完成后播放总结动画 |
| R09 | 复用用户的剧情、视觉素材和视频 |

不要擅自加入投票选凶手、分支结局、答题、倒计时失败、付费服务或多人联网。这些不属于当前范围。

## 可调整的实施默认值

| 项目 | 默认 | 理由 |
| --- | --- | --- |
| 人数 | 当前配置 5 位主线人物；从 JSON 读取 | 展览配置是人数唯一来源 |
| 线索 | 每人 2 条，扫描顺序任意 | 与需求一致 |
| 扫描对象 | 摄像头中的实体印刷图片或图案 | 对应 Vuforia Image Target 模式 |
| 尸体/环境 | 优先复用已有背景，3D 模型可选 | 没有模型时不虚构已存在的 3D 资产 |
| 动画类型 | 已导出的视频 | 与用户已有视频最贴近 |
| UI 语言 | 英文档案内容 | 当前提供素材与用户确认 |
| 输出画幅 | 3840×1152 | 用户指定；background 全屏，其他媒体保持源比例 |
| 档案展示 | 静默显示 3 秒后自动继续；无屏幕按钮、HUD、计数、倒计时或状态提示 | 当前用户最新明确要求 |
| 视频跳过 | 正式默认关闭；调试允许 | 避免误跳过叙事内容 |
| 已解锁档案重扫 | 展示档案 3 秒后回扫描，不重播事件 | 重复扫描不重复计数或自动重播 |
| 每轮进度 | 默认内存状态，新轮清空 | 不串用上一位观众的进度 |
| 结尾 | 结束画面，由“重新开始”启动下一轮 | 自动循环等待时间后续可配置 |
| 数据库 | 本地设备数据库 | 不把日常识别设计成依赖云查询 |

事件视频只在新发现第二条线索后自动入队；档案停留时间由配置控制，当前为 3 秒。最终视频依然必须等最后一个事件视频结束。

## 实施前需要补充但不阻塞 Mock 的信息

真实人数、姓名及文案；每条线索所属人物；每人事件视频；开场与结尾视频；真实目标图；展览运行设备和屏幕方向；实体布展与屏幕背景的关系。

Vuforia 数据库、许可、相机权限、真实打印尺寸和实际照明在真实扫描阶段补齐。Windows 编辑器能使用摄像头测试，不代表某种 Windows 桌面发布包也受 SDK 支持；发布平台需依照当前支持矩阵和实际设备核对。

## 展览空间说明

Vuforia 的扫描输入来自设备摄像头。Unity 虚拟场景里画出的线索图片，不会因为出现在同一个 Game View 就自动成为相机检测到的实体目标。Mock 模式以键盘数字键模拟扫描，不在观众画面显示按钮；现场版本由 Vuforia 识别实体目标。
