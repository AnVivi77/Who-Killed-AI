# 把已有素材放在这里

你不需要重新命名全部素材。如果暂时不想分类，将所有素材和已有文案放入 `00_Inbox_待整理/`，并在 `content/填写说明.md` 写清人物、线索、视频之间的对应关系。

| 目录 | 放什么 |
| --- | --- |
| 00_Inbox_待整理 | 未分类素材和文案 |
| 01_Videos/Intro | 开场先导视频 |
| 01_Videos/SuspectEvents | 每个嫌疑人的事件/作案视频 |
| 01_Videos/Finale | 最终总结视频 |
| 02_Suspects/S01、S02、S03 | 每人的头像、档案相关素材；人数可增删 |
| 03_Clues/TargetImages | 实际扫描的原始图片，与印刷图一致 |
| 03_Clues/DisplayImages | 解锁后在档案中显示的线索图 |
| 04_Environment | 背景、案发现场、尸体或其他场景素材 |
| 05_UI_Audio/UI | 档案框、按钮、图标等 |
| 05_UI_Audio/Audio | 氛围音乐、音效等 |
| 05_UI_Audio/Fonts | 有权使用且包含中文字形的字体 |
| 06_Vuforia/Database | 已导出的 Vuforia 数据库和相关文件 |
| 06_Vuforia/PrintReferences | 打印参考、尺寸记录和现场摆放说明 |

本目录的文字文件只是摆放提示，不是游戏剧情或可用素材。正式许可请在开发环境中配置，不写入这个资料包。

Codex 导入时复制到 Unity 工程并登记路径，保留这里的原始素材。目标图和展示图如果相同，可以让两个资产 ID 指向同一个实际文件，无需复制两份原图。
